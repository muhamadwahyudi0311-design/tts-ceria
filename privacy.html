Kebijakan Privasi

Aplikasi & Game Teka-Teki Silang "Bikin TTS"

Terakhir diperbarui: 5 November 2026

Kebijakan Privasi ini menjelaskan bagaimana Bikin TTS ("kami") mengelola dan melindungi informasi saat Anda menggunakan aplikasi mobile (Android) serta situs web kami di https://tts-studio.my.id.

1. Informasi yang Kami Kumpulkan

Kami sangat menghargai privasi Anda. Aplikasi Bikin TTS tidak mewajibkan pembuatan akun, tidak meminta pendaftaran nama pengguna, alamat email, kata sandi, maupun data kontak pribadi Anda.

  • Data Soal & Jawaban TTS: Soal dan jawaban teka-teki silang yang Anda buat disimpan secara lokal pada memori perangkat Anda (Local Storage / SharedPreferences). Data ini tidak diunggah ke server database pribadi kami.
  • Fitur Berbagi (Share Link): Saat Anda membagikan teka-teki silang ke teman, konten soal dienkode ke dalam parameter tautan URL (misal https://tts-studio.my.id/?d=...) sehingga penerima dapat membuka soal secara langsung di browser tanpa memerlukan akun.

2. Layanan Pihak Ketiga & Iklan (Google AdMob)

Aplikasi ini menggunakan layanan pihak ketiga dari Google untuk mendukung biaya pemeliharaan dan pengembangan melalui penayangan iklan.

Layanan pihak ketiga yang kami gunakan meliputi:

  • Google Play Services: Untuk mendukung kestabilan aplikasi pada ekosistem Android.
  • Google AdMob (Google Mobile Ads SDK): Untuk menayangkan iklan spanduk (banner) dan iklan interstitial di dalam aplikasi.

Google AdMob dapat mengumpulkan dan memproses informasi perangkat anonim sesuai dengan kebijakan privasi Google, termasuk namun tidak terbatas pada:

  • Pengidentifikasi iklan perangkat (Google Advertising ID / AAID).
  • Data diagnostik teknis, performa aplikasi, dan interaksi iklan.
  • Alamat IP (digunakan secara anonim untuk perkiraan lokasi negara/kota guna penayangan iklan yang relevan).

Untuk membaca bagaimana Google mengelola data pengguna, Anda dapat membuka Kebijakan Privasi Google serta Panduan Privasi AdMob.

3. Hak Akses Perangkat (Permissions)

Aplikasi Bikin TTS hanya meminta izin yang mutlak diperlukan untuk berfungsinya aplikasi secara normal, seperti:

  • Akses Internet (INTERNET): Diperlukan untuk memuat iklan AdMob, memuat musik latar dari jaringan, dan membuka tautan teka-teki silang.
  • Status Jaringan (ACCESS_NETWORK_STATE): Diperlukan untuk mendeteksi apakah perangkat terhubung ke internet saat memuat iklan.

Aplikasi kami TIDAK PERNAH meminta akses ke kontak, kamera, mikrofon, lokasi GPS presisi, maupun berkas foto/media pribadi Anda.

4. Privasi Anak-Anak (Children's Privacy)

Aplikasi ini dirancang sebagai sarana hiburan dan asah otak teka-teki silang untuk masyarakat umum (usia 13 tahun ke atas). Kami tidak secara sengaja mengumpulkan informasi identitas pribadi apa pun dari anak-anak di bawah usia 13 tahun. Jika Anda adalah orang tua atau wali dan mengetahui bahwa anak Anda memberikan data pribadi, hubungi kami agar kami dapat mengambil tindakan yang diperlukan.

5. Keamanan Data

Karena kami tidak menyimpan data pribadi pengguna di server eksternal terpusat, risiko kebocoran data akun diminimalkan. Seluruh data progres permainan Anda tetap berada di kendali perangkat Anda sendiri.

6. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu guna mematuhi peraturan perundang-undangan atau pembaruan fitur aplikasi. Perubahan akan berlaku efektif setelah halaman ini diperbarui dengan tanggal revisi terbaru.
